# 송도고 동아리 OX 퀴즈

10개 동아리가 출제한 OX 퀴즈 10문제를 진행하는 웹사이트입니다.

- **참가자 화면** `index.html` — 닉네임과 캐릭터를 고르고 입장하면, 경기장에서 캐릭터를 움직여 O / X 구역을 선택합니다.
- **진행자 화면** `host.html` (`?host=1`) — 문제 → 이동 시작(15초 카운트) → 정답 공개 순서로 진행합니다.

## 진행자 단축키

| 키 | 동작 |
| --- | --- |
| `Space` / `Enter` / `→` | 다음 단계 |
| `←` | 이전 단계 |
| `M` | 음소거 |
| `F` | 전체 화면 |

배경 음악과 효과음은 브라우저에서 실시간으로 합성되며, 별도 음원 파일을 쓰지 않습니다.
